# AI Logging Boilerplate

Production-ready Node.js + Express + Mongoose logging boilerplate.

Includes a publishable server SDK in `server-sdk/` named `dev-js-logger` with `init` and `log` methods for sending application logs.

Quick start:

1. Copy `.env.example` to `.env` and set values.
2. Install dependencies:

```bash
npm install
```

3. Run in development:

```bash
npm run dev
```
